# Codex Working Notes

Use `docs/agent-context.md` as the canonical context.

When modifying files:

- Preserve user-written notes unless explicitly asked to rewrite them.
- Keep documentation structured and reusable across agents.
- Do not add timestamps.
- Prefer small, clear updates to the relevant file over large rewrites.
- When a user answers a clarifying question, update `clarifying-questions.md` and any affected canonical docs.
- Use `knowledge/active-context.md` and `knowledge/handoff.md` to keep operational memory current.
